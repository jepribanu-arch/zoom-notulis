1API Key Gemini

Key hanya tersimpan di browser perangkat ini dan dikirim langsung ke server Google. (Dipakai bersama Notulis AI.)
Cara membuat API key (2 menit)
  1. Buka aistudio.google.com/apikey, masuk akun Google.
  2. Create API key → salin (format AQ. atau AIza).
  3. Tempel di atas → Simpan. Jangan bagikan key.

2Sumber suara rapat

Cara menangkap audio Zoom di laptop (baca sekali)
  1. Buka aplikasi ini di Google Chrome atau Microsoft Edge di laptop Windows.
  2. Tekan Mulai LIVE atau Rekam → muncul jendela "Pilih yang ingin dibagikan".
  3. Zoom aplikasi laptop: pilih tab Seluruh layar (Entire screen) — jangan tab "Jendela/Window" karena tidak membawa audio → nyalakan sakelar "Bagikan juga audio sistem" di kiri bawah → Bagikan.
  4. Zoom di browser: pilih tab Tab Chrome → pilih tab Zoom → nyalakan "Bagikan juga audio tab" → Bagikan.
  5. Video layar tidak direkam — hanya audionya yang dipakai. Bila muncul bilah "sedang berbagi", biarkan; menutupnya = rekaman berhenti.
  6. Pakai headset bila memilih "Zoom + suara saya" agar suara tidak dobel/bergema.

Di mana rekaman lama saya?
  1. Rekaman Zoom di laptop: folder Documents\Zoom → folder per rapat → pilih audio_only.m4a (lebih kecil) atau file .mp4.
  2. Zoom Cloud Recording: buka zoom.us/recording → pilih rapat → unduh Audio Only (M4A) → unggah di sini.
  3. HP / WhatsApp: simpan voice note / rekaman ke File/Galeri → pilih dari HP, atau kirim ke laptop.
  4. Google Drive: unduh file-nya dulu (Drive → Download), lalu unggah di sini.
  5. Beberapa file untuk satu rapat (mis. rekaman terputus) → pilih semuanya; diproses berurutan sebagai satu rapat.
